## What landed

1. **A green test run was citing the other checkout's files** (`71c70eb`).
   This repo is mirrored into `~/Nextcloud` — a different repo on a different
   branch — and the sync carries `__pycache__` with it. A `.pyc` records the
   compiling checkout's absolute path in `co_filename`, and Python revalidates
   it against the local source's mtime+size only, which a file-level sync
   preserves. So pytest collected our files and reported every skip location
   and traceback against the mirror. Audited before touching anything: **99 of
   130** in-tree `.pyc` carried the mirror's path, 47 of them live. **None was
   executing different code** — the sources matched byte for byte. Purged;
   `PYTHONPYCACHEPREFIX` now puts bytecode outside the tree so the sync has
   nothing to carry; `tests/conftest.py` aborts the session if any collected
   test's `co_filename` resolves outside the repo root
   (`FOCUSLOCK_ALLOW_FOREIGN_PYC=1` downgrades to a warning). Verified by
   planting a foreign assertion-rewritten `.pyc` the way the sync would.

2. **The auto-accept flag claimed a door the gate holds shut** (`30dbd96`).
   `_auto_accept_active()` fails closed on an expired or missing deadline, so
   no mesh was accepting anyone — but nothing wrote that verdict back, and
   `auto_accept_nodes` sat `true` in the account JSON forever. That file is what
   an operator reads on the relay to answer "is the door open?", and on
   `eMv8tP9KJL0D` it had been answering *yes*. Both HTTP readouts were already
   honest, so this was never a hole. New `_close_expired_auto_accept_windows()`
   reconciles the flag at every relay start. **An open window is never
   shortened.** 5 tests.

3. **The relay's run dir was world-writable, past an audit gate** (`7e13dc5`).
   `homelab-install.sh` created `/run/focuslock` **0777** plus a tmpfiles.d rule
   to re-apply it every boot. Both relay units run as root (no `User=`), so the
   write bit buys nothing — it was inherited from the desktop-collar installer,
   where it is correct. What it cost: `/webhook/controller-register` is
   admin-token-gated (audit 2026-04-27 M-2) precisely so an unauth caller cannot
   point controller resolution at an address of their choosing, and a
   world-writable directory lets any local account on the relay write
   `controller.json` straight past that gate. Now 0755 in both the chmod and the
   tmpfiles rule. 4 regression tests, mutation-checked.

4. **The lint gate this branch had drifted past** (`36d02b0`). `main` is clean
   under both ruff gates; this branch had accumulated 5 check errors and 16
   unformatted files across 86 commits, so CI would have failed the merge. The
   reason it went unnoticed: **`make lint` was itself broken** — it invoked a
   bare `ruff`, absent on a machine carrying ruff only in `.venv`, so the target
   died instead of linting. Same off-PATH gate failure as `b4010e9`. Also bound
   a loop variable in `staging/qa_device_ui.py` that tripped B023 (latent, not
   live — every call happens inside its own iteration).
