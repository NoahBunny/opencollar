### B — covert removals
- **Silent camera** — deleted `captureSelfieSilent()` (Camera2) + the auto-selfie on evidence
  webhooks; `sendWebhook()` is now text-only. Dropped `CAMERA` from the slave manifest. The
  **wearer-driven photo-task is unchanged** (`ACTION_IMAGE_CAPTURE` → `/webhook/verify-photo`
  + `/webhook/evidence-photo`; the server `evidence-photo` handler was kept/reframed as
  "wearer-submitted photo-task proof only").
- **SMS** — removed `abortBroadcast()` in `SmsReceiver.java`; the `sit-boy` text stays visible.
- **Location** — removed `lat`/`lon` from `ControlService.doStatus()`, deleted `reportLocation()`
  + the `/webhook/location` sink, stripped coordinates from the geofence-breach report (only
  `distance` magnitude is sent). Geofence enforced locally; breach → +$100 paywall via the
  existing `geofence_breach` event. Controller + `web/index.html` no longer read the wearer's
  coordinates (`Confine Home` uses the Collar's own local GPS via `/api/confine-home`). This
  **supersedes the deferred L-2** "signed `/api/location`" idea — there is no location endpoint.

### C — costly-exit, not punish-exit
- Dropped the $500/$1000/$500 tamper cash penalties: server `tamper-recorded` handler is now
  counter-only (increments `lifetime_tamper`, no paywall bump); `AdminReceiver` + the
  `ControlService` mutual-admin monitor reworded (still re-lock as friction + notify, no fine).
- **Never block factory reset**: `applyDeviceOwnerRestrictions()` no longer sets
  `DISALLOW_FACTORY_RESET` and clears it defensively — factory reset is available even as
  device-owner. In-app reset button unhides at **3** escapes (was 150).

### D — panic safeword (`focus_lock_released` is the terminal state)
- **Trigger**: `FocusActivity` — long-press the lock message → `showSafewordDialog()` → type
  `focus_lock_safeword` phrase (set in `ConsentActivity`; default "I NEED OUT") → `confirmSafeword()`
  → starts `ControlService` with `safeword=true` extra → `doSafewordRelease()`.
- **`doSafewordRelease()`** sets `focus_lock_released=1` + `release_timestamp`, best-effort
  `notifyLionSafeword()` (aftercare), then calls the existing `doReleaseForever()` teardown (no
  penalty). `doReleaseForever`'s settings-wipe now preserves every `focus_lock_release*` key.
- **Honored everywhere** so nothing can re-lock a released device: `isReleased()` guards the
  jail-watcher loop, `launchFocus()`, `applyOrdersFromMesh()`, `handleMeshOrder()`;
  `FocusActivity.isLockActive()` returns false if released; **the bridge** (`focuslock-bridge.sh`
  `poll_device`) ceases all enforcement when `focus_lock_released=1` (the critical bit — a
  safeword the bridge could override wouldn't be a safeword).
